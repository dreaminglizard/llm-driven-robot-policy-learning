# 한국어·영어 이중 언어 해석: 초기 단일 의도 비교 준비

2026-10-30의 준비 상태다. 사용자는 이후 **문맥에 따른 원위치, 계속 반복, 동작 중단 후 원위치, 반복 중단**을 추가로 요청했다. 이 문서의 기존 단일 의도 스키마와 복합 지시 거부는 이전 범위의 **연구용 기준**이다. 새 요구를 충족하는 최종 계약이나 지원 완료가 아니다. 복합 지시를 임의로 한 번의 `move`로 축약하지 않는다.

`원위치`가 로봇의 홈 자세, 시작 배치 또는 기억한 배치를 뜻하는지는 실제 실행 상태와 별도 계약으로 구분해야 한다. 반복 대상·시작·중단과 순차 동작 사이의 상태 확인도 아직 이 경로에 없다. 확장 계약과 실행 상태 설계는 별도 작업이며, 이 파일들은 기존 세션·실행기에 연결하지 않았다.

## 보존한 초기 비교 자료

- [개발 자료](bilingual_development.v1.jsonl)는 80문장이다. 기존 한국어 개발 20개에 추가로 같은 20개 상황을 한국어·영어·혼용으로 작성해 한국어 40개, 영어 20개, 혼용 20개다. 세 언어의 짝은 같은 등록 장면과 기대 JSON을 사용한다. 복합 지시의 `reject` 정답은 이전 단일 의도 기준의 표식이다.
- [자료·공통 프롬프트 지문과 생성 설정](bilingual_development.v1.manifest.json)을 고정했다. [공통 프롬프트](bilingual_system_prompt.v1.txt)와 기존 JSON 스키마는 E2B와 E4B가 공유한다. 현재 장면과 기대 정답은 모델에 보내지 않고 로컬 검사에만 사용한다.
- [이중 언어 어댑터](../../raccoon_memory/language_intent_bilingual.py)는 기존 한국어 해석기·스키마를 그대로 사용하며 순수 한국어에는 기존 근거 검사를 적용한다. 영어와 혼용에는 별도 근거·범위 검사를 적용한다. 규칙은 모델의 출력을 거부만 하며 정답 행동을 만들어 채우지 않는다.
- [평가기](../../scripts/evaluate_language_intent.py)는 모델별 같은 준비 발화 1건과 같은 문장 순서, 온도 0·top-p 1·최대 256토큰·시드 20261030·JSON 스키마 응답을 기록하도록 준비했다. 요청마다 원문·시간·토큰과, 측정이 가능할 때만 서버 프로세스의 요청 구간 표본 메모리를 보존한다. 유휴 메모리나 파일 크기를 요청 중 최대치로 대체하지 않는다.

이 초기 이중 언어 설정으로 E2B와 E4B에 대한 **모델 생성 요청이나 개발 평가를 아직 시작하지 않았다**. 따라서 두 모델의 언어별 의미 정확도·지연·토큰·서버 메모리 비교 결과도 없다. 원래 한국어 보류 100문장은 이번 작업에서 열거나 호출하지 않았다. 실제 음성 녹음과 로봇 실행도 하지 않았다.

현재 준비 검사는 모의 모델 응답과 현재 Python 프로세스의 메모리 샘플링을 사용했다. [모의 자료 일관성 검사](bilingual_mock_audit.v1.json)는 개발 자료의 정답 JSON을 그대로 가짜 응답으로 넣어 검사기가 받아들이는지만 확인한 것으로, 모델 정확도가 아니다. 시스템 프롬프트·스키마를 공유한다고 두 모델의 의미 해석이나 복합 제어 안전성이 같다는 뜻은 아니다.
